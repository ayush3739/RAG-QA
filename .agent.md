# 🤖 KnowVex Agent Guidelines & Operating Contract

> **Context:** KnowVex is a production-grade Agentic RAG and Knowledge Intelligence Engine featuring a FastAPI backend, PostgreSQL with `pgvector`, LangChain tool-routing agent, and a React 19 SPA frontend.

---

## 🎯 Standing Project Agents (The 4 Roles)

When working on complex or multi-layered tasks, assign work along these decoupled seams:

| Agent Role | Domain Seam | Primary Responsibilities & Verifications |
|:---|:---|:---|
| **`frontend-specialist`** | `frontend/src/` | React 19, Tailwind CSS, custom hooks, view layouts, Framer Motion, and state management. **Verification:** `npm --prefix frontend run build` |
| **`backend-architect`** | `backend/api/`, `backend/core/` | FastAPI routes, Pydantic v2 schemas, JWT/OAuth auth flows, database models, and SSE streaming endpoints. **Verification:** `python -m py_compile <file>` and route registrations. |
| **`rag-engineer`** | `backend/core/retriever.py`, `backend/agent/` | Hybrid search (pgvector + BM25), Reciprocal Rank Fusion (RRF), CrossEncoder neural reranker, intent router, and citation grounding. **Verification:** `python tests/rag_output.py` |
| **`qa-evaluator`** | `tests/`, benchmarks | Unit test harnesses, integration tests, RAG context precision/recall benchmarks, and regression checks. **Verification:** `pytest tests/` |

## ⚡ Core Operating Rules for Agents

### 1. Production Best Practices First (CRITICAL)
When recommending, designing, or implementing any architectural pattern (routing, authentication, database design, API structures, state management), **ALWAYS present and explain the industry-standard production best practice first**. Never silently choose a shortcut or quick hack just to get quick output. Clearly state the production approach, the reasoning, and any tradeoffs before proceeding.

### 2. Self-Correction Harness & Automated Verification (MANDATORY)
Never report code changes as complete without running the relevant verification command:
- **Frontend changes:** Run `npm --prefix frontend run build` (guarantees exit code 0 and zero TypeScript or Vite bundle errors).
- **Backend changes:** Run `python -m py_compile <path>` or `pytest tests/`.
- **Autonomous Recovery:** If compilation or test errors occur, **do not give up or ask the user prematurely**. Read the compiler/linter error output, diagnose the root cause, apply the fix, and re-verify until exit code 0 is achieved.

### 3. Parallel Subagent Evaluation
Before executing any multi-part or non-trivial task, evaluate whether the work can be decomposed into **parallel subagents along non-overlapping seams** (e.g. Frontend UI vs. Backend API Route vs. Test Suite). If parallelization is viable and efficient, **proactively inform the user and suggest running parallel subagents** to save time.

### 4. Deterministic Chunk Identification
- All document chunk IDs must follow the deterministic format:
  ```python
  chunk_id = f"page_{page_num}_chunk_{chunk_idx}"
  ```
- **RRF Deduplication:** Always merge sparse BM25 and dense vector candidates keyed strictly by `chunk_id`. Never collapse chunks by raw text.

### 5. Grounded Citations & Sanitization
- Every LLM-generated answer from document context must include structured citations:
  ```json
  {
    "chunk_id": "page_5_chunk_2",
    "source": "filename.pdf",
    "page_label": "5",
    "excerpt": "Exact verbatim 20-30 word quote from chunk..."
  }
  ```
- Prompt injection and jailbreak payloads must be sanitized before reaching retrieval or generation.

### 6. Strict Seam Separation
- Do not mix domain logic inside root components. Keep `App.tsx` slim and delegate domain state to dedicated hooks (`useChatStream`, `useDocumentUpload`, `formatters`).
- Keep backend routing, database sessions, and agent tool definitions in their respective modules.

### 7. Frontend Production Standards & Type Hygiene
- **Vite Client Types:** Every Vite + React project must maintain `frontend/src/vite-env.d.ts` with `/// <reference types="vite/client" />` and explicit `ImportMetaEnv` typing for all `VITE_*` environment variables. Never access `import.meta.env` without declared types.
- **Production Baseline Checklist:**
  1. No hardcoded backend URLs or localhost defaults in runtime logic; use `VITE_API_BASE_URL`.
  2. Pure HTML5 History API routing (`pushState` / `popstate`) — no hash routing (`#/`).
  3. Top-level React `ErrorBoundary` with reload/retry capabilities.
  4. Domain logic decoupled from components into specialized hooks (`useChatStream`, `useDocumentUpload`).
  5. Component files kept under 500 lines.
