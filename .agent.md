## 🔑 Core Concepts for Agents

### 1. Chunk ID (Deterministic Cross-Store ID)

```python
chunk_id = f"page_{page_num}_chunk_{chunk_idx}"
# Example: "page_5_chunk_2"
```

**Why it matters:**
- Stable across BM25 and Qdrant (different systems, same ID)
- Enables deduplication in Reciprocal Rank Fusion
- Traceable in UI (answer → exact page/chunk)

**When working with chunks:** Always preserve and use `chunk_id`.

### 2. Hybrid Search Formula

```
Vector results (15) + BM25 results (15)
    ↓
RRF (Reciprocal Rank Fusion):
    score = Σ 1/(k + rank)  ← fair merge, avoids one method dominating
    ↓
Sorted by RRF score, deduplicated by chunk_id
    ↓
CrossEncoder rerank (top 15 → top 10)
```

**When modifying retrieval:** Don't break RRF deduplication; always merge by `chunk_id`.

### 3. Sanitization (Defense in Depth)

**Layer 1:** `answer()` sanitizes before retrieval + generation
**Layer 2:** `generate_response()` defensively sanitizes before LLM call

**Checks:**
- Max 1000 chars
- Block injection patterns: "ignore all instructions", "ignore previous", "you are now"

**When adding features:** Add sanitization at entry points.

### 4. Confidence Score

```python
confidence = max(reranker_scores)
# Range: -15 to +20 (reranker output range)
# Negative = low confidence
# Positive = high confidence
```

**When modifying scores:** Ensure confidence is meaningful for UI to decide when to show/hide answer.

### 5. Citation Building

```python
citations = [
    {
        "chunk_id": "page_5_chunk_2",
        "source": "report.pdf",
        "page_label": "5",
        "excerpt": "...",  # 20-30 word quote
    }
    for chunk in top_5_chunks
]
```

**When generating responses:** Always include citations; they prove answer is grounded.

## 🚨 Common Mistakes to Avoid

### ❌ Break RRF Deduplication
```python
# WRONG: deduplicate by page_content (different chunks with same text get collapsed)
merged = {doc.page_content: doc for doc in all_results}

# RIGHT: deduplicate by chunk_id (stable identifier)
merged = {doc.metadata.get("chunk_id"): doc for doc in all_results}
```

### ❌ Skip Query Sanitization
```python
# WRONG: Pass unsanitized query to LLM
response = llm.invoke(user_query)

# RIGHT: Sanitize first
try:
    safe_query = sanitize_query(user_query)
except ValueError:
    return error_response()
response = llm.invoke(safe_query)
```

### ❌ Use LLM JSON Mode
```python
# WRONG: Force LLM to produce JSON (2-3x cost, fragile)
response_format={"type": "json_object"}

# RIGHT: LLM produces plain text, Python assembles JSON
answer_text = response.content  # plain string
json_output = {
    "answer": answer_text,
    "citations": [...],  # built by Python
    ...
}
```

### ❌ Forget Confidence Scoring
```python
# WRONG: Return answer without confidence
{"answer": "...", "citations": [...]}

# RIGHT: Include confidence for UI
{"answer": "...", "citations": [...], "confidence": 0.82}
```

### ❌ Lose Chunk Metadata
```python
# WRONG: Extract text, lose metadata
chunks_text_only = [c.page_content for c in results]

# RIGHT: Keep full metadata for citations
chunks_with_meta = [
    {
        "chunk_id": c.metadata.get("chunk_id"),
        "text": c.page_content,
        "page_label": c.metadata.get("page_label"),
        "source": c.metadata.get("source"),
        "bm25_score": c.metadata.get("bm25_score"),
        "reranker_score": c.metadata.get("reranker_score"),
    }
    for c in results
]
```

## 💡 Tips for Agents

1. **Always scan the `.md` files first.** They're faster than reading code and explain WHY decisions were made.
2. **Preserve chunk_id in all operations.** It's the glue between BM25 and Qdrant.
3. **Test incrementally.** After any change, run `python tests/test_unit_rag.py` and `python tests/rag_output.py`.
4. **Read error messages carefully.** Our error handling is intentional; they guide fixes.
5. **Respect the phase roadmap.** Phase 2 adds FastAPI (backend separation). Phase 3 adds LangGraph (agent logic). Don't mix phases.
6. **Document your changes.** Update the relevant `.md` file if you add new components.
